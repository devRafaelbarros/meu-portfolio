# Meu Portfólio 

Portfólio pessoal de **Rafael Barros**, desenvolvedor front-end em formação.

🔗 **Site:** https://devrafaelbarros.github.io/meu-portfolio/

## Tecnologias
- HTML5
- CSS3 (Flexbox, Grid, animações e variáveis)
- JavaScript

## Funcionalidades
- Layout responsivo (celular e computador)
- Visual futurista com efeito de vidro e neon
- Menu fixo com rolagem suave
- Formulário de contato

## Como rodar localmente
1. Clone o repositório: `git clone https://github.com/devRafaelbarros/meu-portfolio.git`
2. Abra a pasta no VS Code
3. Abra o `index.html` com o Live Server
